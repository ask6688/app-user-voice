# 公开范围与发布说明

本项目从持续使用的内部用户声音工作流整理而来，使用独立目录、依赖、输出和浏览器状态。没有沿用旧 Git、桌面汇总表、个人运行库或内部文档地址。

## 保留与调整

- 保留原 Python 分析包和七麦浏览器代码，避免重写采集器。
- 通用模式复用规则条件、多标签、统计与原声选择；媒体模式保留片段路由、动态聚合与场景核对。
- 输入改为用户配置的文件，多个输出格式共用报告计划。Excel 每次生成新明细，不维护已有长期工作簿。
- 保留下载完整性、互斥和周期校验；不纳入真实评论、客服原对话、历史报告、截图、日志、凭据和旧 Git 历史。
- 差评率分母明确为有效评分的商店反馈，输出同时提供商店总记录数与有效评分数。

## 展示范围

README 首页只放一张实际 HTML 概览图和一张简洁流程图。原文核对截图、Excel Sheet 说明、统计与采集细节放在 [使用说明](USAGE.md)。不用额外的 Excel 截图、视频、Web 界面或宣传性效果数字。

两张 PNG 来自仓库合成数据的真实报告渲染，经过画面及元数据复核。自动发布检查只允许这两个明确路径，不识别像素中的敏感文字；替换截图后仍需人工复核。

## 发布成熟度

文件导入 → 清洗 → 通用/媒体分析 → HTML、Markdown、Excel 已用合成数据实际运行，适合作为首个本地工具版本。没有钉钉依赖，也没有大模型分析。

七麦已通过本地浏览器回归，但这不是线上采集成功证明。首版可以保留这个可选模块并明确未完成线上验收；如果要宣传线上采集已验证，须先用新 Profile 和自己的账户完成验收。

## 发布检查

- 只提交 `PUBLIC_FILES.txt` 列出的文件；运行发布检查和本地 Demo，人工复核截图与示例。
- 本仓库使用全新的 Git 历史，不继承原工具的提交、快照或 Git 对象。暂存文件应与清单一致。
- 运行数据、报告、缓存、依赖目录、账户状态和本地配置不属于公开范围。
